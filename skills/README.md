# Canonical Project Skills

This is the canonical skill tree for Vibe TTRPG Platform / Eternity Table.

Agents should load only the skills relevant to the current task:

- `vibe-project` — project entry point.
- `product-planning-gate` — critical idea/bug/reference intake, owner questions, planning vault routing.
- `vertical-slice-planner` — Mini-PRD и vertical slices для уже принятой работы, `продолжай` workflow.
- `vibe-ui-architecture` — UI, theme, windows, drawers, workspace, assets/audio.
- `canvas-engine` — canvas, drawing, fog, tokens, portals.
- `knowledge-graph` — entity files, Markdown, wiki links, Obsidian compatibility.
- `mechanics-engine` — dice, stats, formulas, rules math.
- `dynamic-forms` — character sheets, inventory, object/attack forms.
- `multiplayer-sync` — Yjs, websocket rooms, awareness, host/player sync.
- `self-critique` — post-slice quality checks.
- `test-generator` — focused tests/review after implementation.
- `frontend-design` — high-quality frontend visual design when exploring UI directions.

Legacy `.pi/skills`, `.opencode/skills`, and `.agents/skills` paths are forwarding stubs only.
