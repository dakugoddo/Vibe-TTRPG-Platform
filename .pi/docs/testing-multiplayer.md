# 🧪 Инструкция по Тестированию Мультиплеера

> Дата: 2026-05-03
> Назначение: Пошаговая инструкция для тестирования мультиплеера с другом через Hamachi/RadminVPN.
> Связанные документы: `.pi/DEVELOPMENT_PLAN.md`, `.pi/skills/vibe-project/SKILL.md`

---

## Подготовка Виртуальной Сети (Hamachi / RadminVPN)

1. Установите одинаковую программу для LAN-эмуляции (Hamachi или RadminVPN).
2. Хост (ГМ) создаёт новую сеть с паролем.
3. Игрок подключается к этой сети.
4. В приложении рядом с именем хоста появится **IPv4-адрес** (например, `25.55.120.14`). Запиши его.

---

## Запуск Серверов (делает только Хост)

1. Запусти проект: `start.bat`
   - Vite dev server: порт 5173
   - Express сервер: порт 3001
2. Убедись, что брандмауэр Windows не блокирует порты `5173` и `3001`.

---

## Вход в игру

**Хост (ГМ):**
- Открой `http://localhost:5173`
- Выбери роль Host, создай/открой мир

**Игрок:**
- Открой браузер, введи `http://<IP_ХОСТА>:5173` (например `http://25.55.120.14:5173`)
- Выбери роль Player, введи имя
- **Игроку не нужно ничего устанавливать!**

---

## Тест №1: Базовая синхронизация и курсоры

1. Игрок и хост видят перемещение курсоров друг друга (цветные кружки + имена).
2. Хост рисует квадрат — игрок видит мгновенно.
3. Игрок рисует круг — хост видит мгновенно.
4. G+клик = пульсирующий пинг (виден всем).

---

## Тест №2: Undo/Redo (Selective Undo)

1. Хост рисует квадрат.
2. Игрок перекрашивает квадрат в **красный**.
3. Хост **передвигает** красный квадрат.
4. Хост нажимает `Ctrl+Z`.
   - **Ожидаемый результат:** Квадрат возвращается в центр (отменилось движение хоста), но остаётся **красным** (цвет игрока не отменился).

---

## Тест №3: Туман Войны

1. Хост включает Fog Edit Mode (👁️).
2. Хост добавляет просвет (reveal brush) — игрок видит область.
3. Хост скрывает область (cover brush) — игрок снова видит туман.
4. Хост нажимает «Сбросить всё» — игрок видит всё.
5. Хост нажимает «Покрыть всё» — игрок видит полный туман.

---

## Тест №4: Snap-to-Grid

1. Хост включает сетку (квадраты или гексы).
2. Перемещение токена — прилипает к сетке.
3. Удержание Shift при drag — лок по оси X или Y.

---

## Тест №5: Переключение канвасов

1. Хост и игрок на одном канвасе.
2. Хост кликает на портал → оба переходят на новый канвас.
3. Оба видят содержимое нового канваса.
4. Кнопка «Назад» возвращает обоих.

---

## Известные ограничения

- Undo-история сбрасывается при переключении канвасов (Sub-documents).
- Drag во время перемещения токенов сохраняется через CRDT — при большом количестве одновременных перемещений возможна задержка.
