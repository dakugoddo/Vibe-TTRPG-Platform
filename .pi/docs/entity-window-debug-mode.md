# Entity Window Technical Mode

> Дата: 2026-05-24  
> Статус: reference note

## Что это

`full` mode окна сущности - это технический режим. В UI он открывается кнопкой с иконкой bug и теперь подписан как:

```text
Технический режим: свойства, скрытые теги и System ID
```

Он нужен не игроку во время сессии, а GM/разработчику мира:

- посмотреть raw `properties`;
- проверить скрытые/системные теги;
- увидеть `System ID`;
- быстро понять, что реально хранится в `.md` frontmatter/properties после автоматических миграций или drag/drop операций.

## Почему не удалять

Пока Entity schema активно развивается, технический режим экономит много времени при отладке:

- видно, какой ID используется в `[[id]]`;
- можно понять, куда записались `canvasToken`, `_playerOwner`, ресурсы, способности и другие модульные поля;
- проще проверять миграции старых `.md` файлов.

## Правило UX

Обычная работа игрока и GM должна идти через compact tabs/sheets. Технический режим не должен становиться основным интерфейсом механик. Если какая-то часто используемая настройка живёт только в raw properties, значит её нужно вынести в нормальную вкладку/блок.
