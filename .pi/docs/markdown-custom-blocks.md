# Markdown Custom Blocks

Дата: 2026-05-18

Кастомные блоки работают в описании любой сущности и в заметках персонажа. Markdown по-прежнему хранится обычным текстом в `.md`, поэтому совместимость с Obsidian не ломается.

## Inline Rolls

```md
!roll 2d6+$strength
!roll $agility
!roll 1d20+5
```

- `$variable` сначала ищется в текущей сущности, затем в остальных сущностях.
- Для навыков читается `properties.skills.<name>.rank`.
- Если выражение сводится к числу, оно считается пулом d6: `$agility` при значении 3 даст `3d6`.
- Результат отправляется системным сообщением в чат.

## Stats Block

````md
```stats
Телосложение: attributes.constitution
Когниция: attributes.cognition
Уклонение: defense.evasion
Броня: defense.armor
```
````

Если тело блока пустое, показывается стандартный набор основных статов. Значения читаются из `properties`; объект вида `{ base, adhoc }` отображается как сумма.

## Inventory Block

````md
```inventory
```
````

Показывает предметы-дети текущей сущности, группирует по категориям `оружие`, `броня`, `расходуемое`, `другое`, выводит количество, экипировку и суммарный вес.

## GM-Only Block

````md
```gm-only
Эта информация видна только ГМу.

[[Секретная фракция]]
!roll 1d20+3
```
````

Для игроков содержимое не рендерится; они видят только короткую плашку скрытого блока. У ГМа внутри блока рендерится обычный Markdown, но вложенные кастомные блоки отключены, чтобы избежать рекурсивных конструкций.
